## Tema: “Backrooms: No hay Salida”

Este repositorio contiene todos los elementos necesarios para la compilación y ejecución de un simulador de entorno interactivo en 3D basado en la estética de los Backrooms. La aplicación fue desarrollada en C++ utilizando la API gráfica OpenGL y estructurada para ser compilada en el entorno de Visual Studio.

## Estructura del proyecto

La estructura de este proyecto es la siguiente. A continuación se detallan los directorios principales:

- **Dependencias:** aquí se encuentran las librerías, cabeceras y configuraciones necesarias para compilar el proyecto gráfico.
- **docs:** incluye la presentación creada para la defensa del proyecto.
- **models:** contiene los modelos 3D en formato `.obj` junto con sus respectivos archivos de materiales utilizados en el entorno.
- **shaders:** incluye los códigos fuente de los programas de sombreado (Vertex y Fragment shaders) encargados del renderizado y la iluminación.
- **sounds:** almacena los archivos de audio implementados para los efectos de sonido y la ambientación de la escena.
- **src:** código fuente principal en C++ implementado para la lógica de la aplicación y el motor gráfico.
- **textures:** imágenes utilizadas para los menús de la interfaz.
